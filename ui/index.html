Endorsements on file

Hazmat is the only endorsement the game models. A tanker is a trailer and what gates it is what is inside it — a fuel tanker is class 3, a gas tanker class 2, a food-grade tanker nothing at all. Doubles and triples are a trailer configuration, not a licence. Which hazmat classes you are cleared for is tracked separately, as you unlock them.
